# 图表分流修复

## 根因

无历史素材样本暴露共用分流遗漏：生命周期、批次划分、功能点分布未识别为关系图；映射表未识别为原生表格。旧思路可能绕过新规则，补好图后仍按旧需求追加位图占位。模型还把拟定权限策略表误标成真实材料，阻止补表。

## 修复

- 规划、生成资格判断、占位补齐共用关系图与表格规则。
- 正文收尾重新规范旧思路，不再让旧分类绕过修复。
- 原生方案表允许从误标的material转出；真实截图、实测、签章、客户提供材料继续保护。
- 关系图补绘不再接收表格需求。
- 转出的表格需求不得静默省略；已有同名策略标题下的表格则复用，避免补第二张空表。
- 引言不增加详细图表；渲染仍在导出期批量进行。

## 验证

生成修复13项、图像生成15项、图片检索12项共40项通过。用独立项目16重跑功能测试、数据安全、测试过程安全、进度管理4个节点；实际检查4处图片占位及相关图片生成错误消除。权限映射章最终有7行Markdown表格、无占位及重复空表。过程曾出现表格被误标材料及重复补空表，两处均补测试并重新验证，没有以首轮结果冒充最终通过。
