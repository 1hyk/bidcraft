# 工作台目录与正文交互整理

日期：2026-10-21。此记录更新此前将02全部放入抽屉的交互方案。

## 最终职责

- 01项目理解：核对招标来源、分类与响应范围。
- 02目录与思路：使用完整工作区整理章节、查看与编辑唯一的章节思路；目录结构操作集中在此模式。
- 03正文编辑：保留同一章节与唯一TipTap编辑器，思路默认折叠，可展开；进入已有项目默认回到正文，避免旧完成状态造成空白检查页。
- 要求关联与编写设置：辅助抽屉，集中现有章节关联、排版和篇幅入口。不会因关闭抽屉改变原来的工作模式。
- 04检查与导出：保留检查抽屉及定位后收起行为，与设置抽屉互斥。

## 生成和保存

生成正文继续走现有排版、篇幅确认入口；正式启动全文编写后切入正文模式。编辑思路不自动改写已生成正文。离开编辑中的思路前保存，失败时阻止切换并保留草稿。重新生成目录继续保留原有破坏性替换提示。

## 验证范围

35项前端检查通过，生产构建通过。在项目26真实浏览器中验证目录选章、思路显示、设置内容、收起设置后返回及进入同章正文。未修改项目26正文，未重新调用模型生成整稿。本轮验证针对交互和保存保护，不代表内容真实性、页数与导出排版重新获得全流程验收。
