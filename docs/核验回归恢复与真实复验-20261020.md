# 核验回归恢复与真实复验

## 已确认的回归

旧框架将未来履约任务错分为现阶段真实证明或递交事项，导致实飞、监视、交付等要求绕开正文核验。失败报告有9条待阶段核对、3条核验错误、4条部分响应。

进一步检查发现，4条部分响应把评分细则中的低分档描述当成独立履约义务，要求方案自述“存在不合理或技术风险”“有缺失”，甚至声明自己属于3—7分档。这个判断明显不适用于技术方案覆盖核验。

## 本轮收敛

- 生产正文核验撤下强制义务拆分与自动阶段分流，恢复逐条要求、候选证据及引用校验。
- 实际飞行、验收交付、签署验收书、培训、售后和工期，检查拟议方法与履约安排，不要求投标时已经完成。
- 实际投标成品字段独立提醒：仅对明确的编制索引页码要求保留最终文件待核对，索引建立及章节对应仍参与正文核验。没有给低空项目写死章节、要求ID或数值。
- 无关待补事实不自动降低技术响应结论，真实事实风险仍由问题处理负责。
- 旧失败报告及正文快照保留，检查版本更新使旧结论不再作为当前依据。
