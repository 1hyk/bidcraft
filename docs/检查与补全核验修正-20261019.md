# 检查与补全核验修正

本轮针对项目15出现的证据引用校验失败、范围混用和处理入口误导进行修正，不修改正文。

1. 技术要求响应与其他投标事项分开展示。按标题明确识别的限价、报价、资格及递交事项不计入技术正文统计，仍保留原要求和来源；不明确项保守留在技术核查范围。此分类不能替代人工判断。
2. 返回结果增加review_state，区分核验完成、未核验和调用/证据失败。失败不作为missing缺项结论，显示重试或人工核对。
3. 证据改为完整段落组合，过长段落按完整句子拆分。正文代码块不作为证据；不再固定750字腰斩片段。检索仍是候选召回，不保证覆盖全书所有有关片段。
4. 批次从4条缩至2条；失败项逐条重试一次，仍失败不判通过。全组无有效结果保留原报告。
5. 问题处理按占位内容提示可能的处理方式，仅可能需要公司事实的条目显示查库按钮，岗位、人数、技术阈值等不再默认要求上传公司文件。判断是启发式提示，混合项仍须人工核对。
