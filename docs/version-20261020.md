# 内部试用版更新 · 2026-10-20

本版聚焦技术方案编写主流程及验证，不包含客户原始招标文件、公司材料、数据库或生成稿。

## 主要调整

- 招标要求贯穿目录、思路与正文，完善多级目录、父子章职责和篇幅分配。
- 技术要求覆盖检查与待补资料分离，支持来源文件及原文上下文回查。
- 历史知识素材按领域和归属过滤，历史图片匹配、去重及实际导出复用。
- 关系图、原生表格、生成插图与真实材料按用途分流，修复旧思路绕过分流的问题。
- 完善标题编号、独立历史图片居中题注、连续图题归属及甘特图引用兼容。
- 排版保存与页数预估联动，使用本地实际分页验证目标页数。
- 公司资料候选提取与确认流程完善；经验库导航暂时隐藏。
- 首页使用嘉驰官方公开Logo并调整项目导航、卡片和创建入口。

## 验证范围

已在独立项目中验证无历史素材及低空同领域历史素材两种生成路径，覆盖解析、目录、正文、检查、导出、实际分页和历史图片嵌入。相关回归检查及前端生产构建通过。

## 使用边界

本版用于内部辅助编写。公司能力、人员、资质、业绩、履约承诺和专业内容仍需人工审核。目标页数为带容差的控制目标，不能保证所有样本首轮达标；复杂长表和小字图仍需排版复核。自动检查不替代投标审核。
