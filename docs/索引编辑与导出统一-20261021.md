# 索引编辑与导出统一

## 已实施

- 明确需要索引且已有目录时，通过显式同步接口创建正式索引节点，位于现有编制子树内。
- 使用原有 `chapter_node` 和 `section_content`，没有新建正文存储。节点通过 outline 的 `_document_role` 标记用途。
- 已有节点不覆盖，重复同步不重复创建。不需要索引的新项目不自动创建。
- 原有编辑器可编辑评分项、章节文字和表格；页码是独立的章节引用原子，可下拉选择对应章节。
- 编辑器提示修改章节名称文字不会改变页码关联。
- 导出前置索引仅渲染保存的正式内容，不再重新生成隐藏索引，也不在正文遍历时重复输出。
- 页码引用导出为 PAGEREF；无效目标输出明确提示，检查清单也列出失效引用。
- 索引不参与正文 AI 生成、批量改写或正文扩写预算；单章生成与重新生成思路有保护。
- 检查取数包含索引正文，因此后续重新核验能读到它；未调用模型刷新结论。
